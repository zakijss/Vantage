# Security policy

## Reporting a vulnerability

Please report security problems privately through GitHub: on this
repository's Security tab, choose "Report a vulnerability", or go straight to
<https://github.com/zakijss/Vantage/security/advisories/new>. Don't open a
public issue for them.

Say what you found, the release or commit, and how to reproduce it. The reply
comes in the advisory's thread, and a fix ships in a new release.

## Supported versions

Only the latest release gets fixes.
